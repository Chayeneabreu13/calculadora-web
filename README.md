# 🧮 Calculadora Web

Calculadora desenvolvida com **HTML, CSS e JavaScript**, como projeto de prática em desenvolvimento Front-end.

## 🚀 Funcionalidades

- Operações matemáticas básicas
- Interface simples e moderna
- Botão para limpar os valores
- Cálculos realizados com JavaScript

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
